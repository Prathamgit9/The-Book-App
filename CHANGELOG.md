# Changelog

## [0.1.0] — 2026-09-23

### Added
- Initial Android Jetpack Compose application.
- Literary / old-book visual direction.
- Home, Library, Lists and Stats sections.
- Local book persistence.
- Open Library title/author search and cover artwork.
- Reading statuses: Reading, TBR, On Hold, Completed and DNF.
- Page progress tracking.
- Start/finish dates.
- Personal notes.
- Five-star book ratings.
- GitHub Actions Android build.
- Debug APK artifact generation.

### Notes
This is the first development release. The data model and UI will continue to evolve toward the complete reading journal specification.
